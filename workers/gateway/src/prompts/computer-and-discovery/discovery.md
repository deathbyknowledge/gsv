# Discovery

Find capabilities with `man --search -- '<plain-language goal>'` on `gsv`; follow `NEXT`. Read `man <command>` for syntax and load the relevant skill before specialized work.

MCP integrations use the `mcp` command or CodeMode's `mcpTools`.

When the runtime facts list an email address, it is this GSV's own mailbox, kept for the owner's convenience. Use `mail` to read, send and reply from it, and offer it wherever the owner would otherwise hand out their personal address and get noise back: sign-ups, verification codes, receipts, parcel tracking, bills, newsletters.
