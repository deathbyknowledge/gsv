# @humansandmachines/gsv

Public TypeScript SDK and protocol contracts for [GSV](https://gsv.space), an
open-source, user-owned personal intelligence system.

The package provides the GSV client, host bridge, package SDK, syscall types,
and stable runtime protocol helpers. Subpath exports let consumers import only
the boundary they need, including `@humansandmachines/gsv/client`,
`@humansandmachines/gsv/protocol`, and `@humansandmachines/gsv/sdk`.

Runtime deployments, the web shell, adapters, and the CLI remain in the
[GSV repository](https://github.com/deathbyknowledge/gsv). This package does
not contain hosted-service policy or provider credentials.
